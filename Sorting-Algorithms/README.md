# Sorting Algorithms

Educational sorting implementations with complexity summaries and runnable examples.

- Bubble Sort — repeatedly swaps adjacent out-of-order elements.
- Selection Sort — repeatedly selects the smallest remaining element.
- Insertion Sort — inserts each element into the sorted prefix.
- Merge Sort — divides the array and merges sorted halves.
- Quick Sort — partitions around a pivot.
- Heap Sort — builds a heap and removes elements in priority order.
- Radix Sort — sorts integers one digit at a time.
