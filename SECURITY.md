# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 5.1.x   | ✅        |
| 5.0.x   | ❌        |
| 4.0.x   | ✅        |
| < 4.0   | ❌        |

This project follows the supported-versions policy above. Only the versions marked as supported will receive security fixes.

## Reporting a Vulnerability

Please report security issues privately so we can investigate and, if needed, fix them before public disclosure.

Preferred reporting options:
- Create a private GitHub Security Advisory (recommended) — https://github.com/Root-Hunter1/Root-Hunter1/security/advisories (if available)
- Or email: security@example.com (replace with your address)
- If you need to encrypt your report, use our PGP key: <PGP_KEY_FINGERPRINT> (replace with actual fingerprint)

When reporting, please include:
- Affected version(s)
- A clear description of the vulnerability
- Steps to reproduce or a minimal proof-of-concept
- Severity impact and any mitigations you know
- Contact information so we can follow up

## Response Time

- We aim to acknowledge all valid reports within 3 business days.
- We will provide a remediation plan and timeline within 7 business days where possible.
- Critical vulnerabilities will be prioritized and patched as quickly as possible.

## Disclosure Policy

We prefer coordinated disclosure. We will:
- Work privately with the reporter to evaluate and fix the issue.
- Request a reasonable embargo for public disclosure to allow time for a fix and release.
- Credit reporters in release notes or an ACKNOWLEDGMENTS file unless they request anonymity.

If you publicly disclose a vulnerability without prior coordination, we may:
- Still work to remediate, but may mark the issue as public and adjust timelines accordingly.

## CVE and Third-Party Coordination

If a fix is security-relevant and meets CVE criteria, we will request a CVE ID and coordinate with the reporter as needed.

## Acknowledgements

We appreciate responsible disclosure. Thank you for helping improve the security of this project.
