## Overview

Root-Hunter1 is a learning-focused collection of Python projects, algorithms, data structures, networking examples, and system-level experiments.

## Included Topics

- Python programming
- Algorithms and data structures
- UDP/TCP networking
- Asyncio
- Multi-threading
- C, C++, Go, and Rust
- Performance and concurrency
- Practical coding experiments

## Project Structure

```text
Root-Hunter1/
```

## Getting Started

```bash
git clone https://github.com/Root-Hunter1/Root-Hunter1.git
cd Root-Hunter1

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
```

## Example

```python
from algorithms.sorting.quick_sort import quick_sort

arr = [5, 2, 9, 1, 7]
print(quick_sort(arr))
```
